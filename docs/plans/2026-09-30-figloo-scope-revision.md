# Figloo 範圍修訂：由 agent 主導的設計稿探索

日期：2026-09-30  
狀態：方向與截圖權限已由使用者決定，M3 從可行性驗證開始  
依據：Claude Code 實際使用 Figloo 的回饋，以及使用者對回饋的決策

## 使用者決策

1. 目標使用者是工程師，只支援 Figma 的檢視權限，不驗證編輯模式。
2. 「送給 agent」先做成複製內容；把訊息直接推進 agent 對話（Claude Code channels）之後再評估。
3. Agent 可以不依賴使用者的選取，自行瀏覽設計稿的頁面與元件，並查詢參數。
4. MCP 要能截圖，讓 agent 從圖片理解整份設計稿，再透過 MCP 取得需要的資料。

## 要取代的工作方式

在 Figloo 之前，使用者自己截圖設計稿交給 agent，再用文字描述要做的內容；有些專案另外搭配 Zeplin MCP 提供設計規格。Figloo 要在 Figma 設計稿上直接提供這兩件事：讓 agent 看得到畫面，也讀得到規格。

## 目標使用情境

使用者打開 Figma 設計稿，檔案裡有多個頁面，每頁有大量畫面、說明與相關頁面。使用者在 agent 中用文字描述需求，agent 透過 MCP：

1. 列出頁面與頁面中的頂層畫面。
2. 擷取頁面或畫面的截圖，從圖片理解內容。
3. 找到相關的畫面與元件後，逐層列出結構並讀取參數。

## 對原計畫的影響

| 原計畫 | 修訂後 |
|---|---|
| 以使用者選取的元件為定位錨點 | 選取是入口之一；另外可以從頁面進入 |
| 全程不掃描整份文件，第一版不做全文件搜尋 | 由 agent 主導、逐層進行，每次呼叫仍有預算；仍不在背景預先掃描 |
| 預覽截圖列為後續評估 | 提前到 M3；截圖只作視覺參考，不當作精確參數 |
| 「傳送給 agent」不列入 | 先做複製內容；直接推送之後再評估 |

不變的限制：只透過 DOM 與網頁 UI；不使用 REST API、官方 MCP、plugin、內部 JavaScript store 或 WASM 記憶體；不修改設計內容。

## 2026-09-30 實測

| 項目 | 結果 |
|---|---|
| Service worker 只有 figma.com 權限時呼叫 `captureVisibleTab` | 失敗：`Either the '<all_urls>' or 'activeTab' permission is required.` |
| 以 `toDataURL` 讀取 Figma 畫布元素 | 只得到單一顏色，不可行 |
| 以合成點擊切換頁面列表中的頁面 | 可行，訪客模式也能切換，網址 `node-id` 隨之改變 |
| 背景分頁點擊展開按鈕 | 不生效（M2 紀錄） |

尚未驗證：選取、縮放到選取範圍、切換頁面與截圖在背景分頁是否生效；`activeTab` 授權在 Figma 站內換網址後是否仍有效。預期這些操作都需要 Figma 分頁留在畫面上。

## M3 工具草案

| 工具 | 用途 | 需要分頁在前景 |
|---|---|---|
| `list_pages(tabId)` | 列出檔案中的頁面與目前頁面 | 否 |
| `explore_page(tabId, page?)` | 必要時切換頁面，回傳頂層圖層與 `contextId` | 切換時需要 |
| `get_anchor(tabId)` | 以使用者選取為入口（M2 已有） | 否 |
| `get_neighbors(..., depth?)` | M2 已有；`depth` 最多 3 層，總數仍受每次 50 個上限 | 展開收合的圖層時需要 |
| `inspect_nodes(contextId, refs, fields)` | 讀取檢視權限下的屬性面板，每次最多 5 個，每個欄位附狀態 | 需要 |
| `capture(contextId, ref?)` | 截取頁面全覽或某個畫面，回傳圖片 | 需要 |

截圖流程：選取目標畫面、縮放到選取範圍、擷取可見範圍並裁切畫布區域、還原使用者的選取。圖片長邊縮到 1568 px 以內，另訂圖片大小上限，與 32 KiB 的 JSON 上限分開計算。

## 已決定的細節

1. 截圖權限使用 `<all_urls>`，讓 service worker 不需要使用者點擊就能截取分頁。
2. Figma 分頁在背景時回報錯誤，請使用者把 Figma 放到畫面上；不主動把 Figma 帶到前景。

## 下一步

先在 Arc 做可行性驗證，Figma 分頁需留在畫面上：選取後讀取屬性面板並還原、縮放到畫面並截圖、切換頁面、背景分頁的行為、`activeTab` 授權的有效期間。通過後再實作上述工具與 popup。
