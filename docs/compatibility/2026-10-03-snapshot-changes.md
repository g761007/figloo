# 快照的變更比對（snapshot diff）

狀態：實作完成。在使用者的 Arc 上，設計沒變時連續兩次重讀都比對出 0 個變更  
日期：2026-10-03  
範圍依據：[Roadmap 第一批](../plans/2026-10-02-roadmap-batch-1.md)的 M6

## 內容

| 項目 | 內容 |
|---|---|
| 何時比對 | 讀完一份新的完整快照時，和同一個 root 的上一份完整快照比對；分次讀取的快照在最後一次呼叫時比對 |
| 比對基準 | 上一份快照不論是否過期都可以用。過期的快照保留 30 天，之後在寫入同一份檔案的新快照時清除 |
| 結果 | 快照檔記下 `changes`：新增的 ref、被刪除的圖層（ref、名稱、類型、parent），以及變更的圖層與變更面向。`snapshot_layer` 的結果列出三者的數量，與最多 20 個被刪除的圖層 |
| 變更面向 | `name`、`type`、`hidden`、`moved`（parent 改變）、`bounds`（任一邊差 1 px 以上）、屬性面板的群組（`layout`、`appearance`、`typography`、`component`、`other`）、`content`（文字內容）、`exports`（兩次都確認過匯出區塊時才比） |
| 大綱 | 新增的圖層標記 `[new]`，變更的標記 `[changed: …]` |
| `query_snapshot` | `changed: true` 只列出新增與變更的圖層 |

## 做法

- 比對以 ref 對齊。快照不讀 instance 內部，其他圖層的 ref 在重新載入後不變。
- 位置以 1 px 為門檻、不比位置來源，避免同一個位置在不同次讀取時有小數誤差。
- 屬性面板各區塊的標題不比：文字分段的標題就是那一段文字，文字改變已由 `content` 涵蓋。

## 驗證

| 項目 | 結果 |
|---|---|
| 單元測試 | 新增、刪除、各變更面向、1 px 以內的誤差、標題不比、未確認的匯出設定、大綱標記、`changed` 篩選、快取時仍回報、過期 10 天的基準可用、超過 30 天後清除 |
| Arc：設計沒變時重讀（frame 999:61586，203 層） | 第一次與約 8 小時前、另一次頁面載入的快照比對，第二次與第一次比對，兩次都是 0 個新增、0 個變更、0 個刪除，各約 23 秒 |

## 未驗證

- 真實的設計變更：使用者只有檢視權限，無法修改測試檔，所以有變更的情況只由單元測試涵蓋。
