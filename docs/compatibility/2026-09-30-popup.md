# 工具列 popup

狀態：實作完成，單元測試與訪客分頁整合測試通過，使用者也在 Arc 上選取圖層後實際使用過  
日期：2026-09-30  
範圍依據：[範圍修訂](../plans/2026-09-30-figloo-scope-revision.md)。「送給 agent」先做成複製內容，不固定錨點，也不放截圖。

## 內容

- 檔案名稱、目前頁面與存取權限。
- Figloo 能否讀取這個分頁，與工具列圖示的判斷相同，並附上限制的原因。
- Agent 是否已連線，文字與工具列提示相同。
- 選取一個圖層時，顯示從頁面開始的祖先路徑、圖層名稱與類型，以及最多 20 個直接子層。
- 沒有選取、選取多個，或是訪客無法選取時，說明原因。
- 「Copy prompt for the agent」按鈕，以及要複製的提示內容預覽。

## 做法

- Popup 把分頁 ID 交給 service worker。Service worker 重新探測分頁，再依序執行 `list_pages`、`get_anchor`，以及 `list_neighbors` 的祖先與子層。
- 這些操作和 agent 的請求走同一個分頁佇列，所以不會和進行中的匯出或截圖交錯。
- 子層收合時，讀取子層需要展開再收回，圖層面板會短暫變動。祖先與頁面只讀取已顯示的內容。
- 名稱一律以文字插入畫面，不當作 HTML 解析。
- 有選取時，提示寫出檔案、分頁 ID、頁面、圖層 ref、路徑、前 10 個子層，以及圖層連結；instance 內的圖層 ID 只在這次頁面載入有效，所以不附連結。提示也要求 agent 先以 `get_anchor` 確認 ref，不符時請使用者重新選取。
- 沒有選取時，提示請 agent 從 `list_pages` 與 `explore_page` 自行探索。
- 複製使用 `navigator.clipboard.writeText`，不需要 `clipboardWrite` 權限。失敗時會選取預覽中的文字，請使用者按 Cmd+C 或 Ctrl+C。

| 單元測試：畫面 | 7 項：路徑與子層、名稱中的 HTML 以文字顯示、沒有選取的說明、複製成功、複製被拒時選取文字、無法讀取的分頁、沒有設計稿的分頁 |
| 訪客分頁整合測試 | 以分頁開啟 popup 頁面：顯示檔名與分頁、訪客限制、agent 已連線，以及探索用的提示。按下複製後貼到輸入框，內容與提示完全相同 |
| 版面 | 以模擬資料在 Chromium 截圖檢查淺色與深色模式，修正了寬度溢出與深色模式按鈕對比 |
